2. USER AUTHENTICATION APIS
--------------------------------------------------------------------------------

2.1 POST /api/auth/register
Description: Registers a new user, creates their initial profile, and returns an authentication token.
HTTP Method: POST
Exact Path: /api/auth/register
Path Parameters: None
Query Parameters: None
Request Headers: Content-Type: application/json

Request Body:
{
  "email": "student@example.com",     // Required, string (unique)
  "password": "Password123!",         // Required, string
  "full_name": "Saurin Modi"          // Required, string
}

Response (201 Created):
{
  "message": "User registered successfully!",
  "token": "user_token_1",
  "user": {
    "created_at": "2026-09-25T01:00:00",
    "email": "student@example.com",
    "full_name": "Saurin Modi",
    "id": 1
  }
}

Error Responses:
- 400 Bad Request:
  {"error": "Email, password, and full name are required."}
- 400 Bad Request:
  {"error": "An account with this email already exists."}


2.2 POST /api/auth/login
Description: Authenticates an existing user by email and password and returns a token.
HTTP Method: POST
Exact Path: /api/auth/login
Path Parameters: None
Query Parameters: None
Request Headers: Content-Type: application/json

Request Body:
{
  "email": "student@example.com",     // Required, string
  "password": "Password123!"          // Required, string
}

Response (200 OK):
{
  "message": "Login successful!",
  "token": "user_token_1",
  "user": {
    "created_at": "2026-09-25T01:00:00",
    "email": "student@example.com",
    "full_name": "Saurin Modi",
    "id": 1
  }
}

Error Responses:
- 400 Bad Request:
  {"error": "Email and password are required."}
- 401 Unauthorized:
  {"error": "Invalid email or password."}
